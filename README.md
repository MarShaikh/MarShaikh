# hey, i'm marouf 👋

I build the infrastructure that ML and data teams run on: stuff like job orchestration, cloud deployment, packaging, and the plumbing that lets LLM tools touch real systems safely.

Right now that's at the University of Oxford, where i work on [MDV](https://github.com/Taylor-CCB-Group/MDV), an open-source data platform that has to run on a laptop, an HPC cluster and GCP. before that I was at LSHTM, a biotech called DIOSYNVAX, and Unify (YC W23).

The part of the job I enjoy most is the messy middle, when something works on one person's machine and now has to work for everyone, every time. That's also where the best bugs live. my favourite one so far took days to find and [came down to two characters](https://blog-site-b0e.pages.dev/Two-characters-broke-my-STAC-API).

### what i'm up to

- Building a jobs framework for MDV, so the same analysis runs on a laptop or a Slurm cluster without anyone changing a line
- [`carryon`](https://github.com/MarShaikh/carryon): I got tired of rebuilding my Claude Code setup on a machine, so I built a tool that packs it up and moves it. Works with Codex and Cursor too.
- [`key-cli`](https://github.com/MarShaikh/key-cli): a small CLI that keeps secrets in the macOS keychain behind Touch ID, making it easier to stay away from storing them in `.env` files
- learning CUDA
